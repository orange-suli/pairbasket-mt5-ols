# PairBasket v10.1 OLS 参数优化回测报告

## 1. 报告目的

本报告基于 `PairBasket_v10_1_OLS_OptimizationMetrics.csv` 的完整优化结果，对 OLS Residual Spread 策略在 M15 与 M30 两个周期下的参数表现进行比较，重点评估：

- 首仓阈值 `ZScoreOpen`
- 继续偏离加仓间距 `AddZStep`
- 线性加仓增量 `AddLotStep`
- 收益、Sharpe、Profit Factor、Score
- 最大权益回撤
- 单个 Basket 最大浮亏
- 最长/平均 Basket 持仓时间
- 极端 Z 持续时间与回测结束未解决 Basket 风险

本轮的主要目标不是直接确定最终实盘参数，而是定位具有稳定优势的参数区域，并识别需要继续向搜索边界外扩展的方向。

## 3. Score 的含义

当前优化版本的 Score 是综合风险收益评分，不是单纯按照净利润排序。

核心部分奖励：

- 净收益率
- Sharpe
- Profit Factor 超过 1 的部分

同时惩罚：

- 最大权益回撤
- 单 Basket 最大浮亏
- 超过 30 天的最长 Basket 持仓
- 回测结束仍未解决且超过 7 天的 Basket
- 连续超过 24 小时的极端 Z
- Basket 样本数不足 30

因此，**Score 越高，代表当前评分体系下综合风险收益越好**。但 Score 仍然只是筛选工具，最终参数仍需要结合回撤、尾部 Basket、参数稳定性和样本外测试判断。

---

## 4. 总体结论

### 4.1 M15 明显优于 M30，但二者最优参数方向不同

本轮最明显的结果是：

- **M15 的优势高度集中在 `ZScoreOpen = 3.0`**。
- **M30 的优势高度集中在 `ZScoreOpen = 1.5`**。
- M15 更适合等待更极端的偏离后进场，并允许适度线性增仓。
- M30 更适合更早进场，但明显偏好等手数或很轻的线性增仓。

因此，M15 与 M30 不宜继续强行寻找一套共用参数，后续应分开寻优。

### 4.2 当前最佳 Score 并不等于最推荐参数

全表 Score 第一名为：

- M15
- `ZScoreOpen = 3.0`
- `AddZStep = 1.0`
- `AddLotStep = 0.04`
- Score = **375.41**
- Net Profit = **4813.27**

但其最大权益回撤达到 **17.53%**，单 Basket 最大浮亏达到 **2342.38**。这说明高 Score 和高收益中包含了较强的仓位放大因素。

从风险收益平衡来看，更值得优先验证的是：

- M15 / 3.0 / 2.0 / 0.02
- M15 / 3.0 / 2.0 / 0.04

其中 `3.0 / 2.0 / 0.02` 的 Sharpe 为全表候选中的最高水平之一，同时最大回撤和单 Basket 尾部亏损显著更低。

### 5.1 风险收益解读

#### A. M15 / 3.0 / 1.0 / 0.04：收益最高，但仓位风险最大

该组合在本轮取得最高 Score 和最高净利润，但最大回撤为 17.53%，单 Basket 最大浮亏 2342.38，显著高于其他 M15 优秀组合。

它更像“高收益型”参数，而不是当前最适合作为实盘基准的参数。`AddZStep = 1.0` 意味着加仓较密，`AddLotStep = 0.04` 又会快速扩大后续层级的仓位，因此收益与尾部风险同时被放大。

#### B. M15 / 3.0 / 2.0 / 0.04：较好的激进平衡型

与最高收益组合相比：

- 净利润由 4813 降至 1691
- 最大回撤由 17.53% 降至 6.89%
- 单 Basket 最大亏损由 2342 降至 760
- Sharpe 由 1.624 提升至 1.772

说明把加仓间距从 1.0 扩大至 2.0 后，虽然绝对收益减少，但单位风险质量明显改善。

#### C. M15 / 3.0 / 2.0 / 0.02：当前平衡型首选

该组合的核心优势是：

- Sharpe **1.786**，在重点候选中最高
- 最大回撤只有 **4.84%**
- 单 Basket 最大亏损只有 **514.73**
- PF 仍达到 1.340
- 净利润 1120.34

相比 `3.0 / 2.0 / 0.04`，牺牲部分绝对收益后，风险继续明显下降；相比等手数版本，又保留了一定的加仓成本改善能力。

因此，从当前单区间回测结果看，该组合最适合作为后续样本外验证的主基准之一。

#### D. M15 / 3.0 / 2.0 / 0：保守型基准

该组合不增加加仓手数：

- 最大回撤仅 **2.56%**
- 单 Basket 最大亏损 **260.07**
- Sharpe **1.729**
- 净利润 571.95

它的意义非常重要：证明并不是必须通过线性增加手数才能获得较好的统计质量。后续应始终保留 `AddLotStep = 0` 作为对照基线。

#### E. M30 / 1.5 / 1.5 / 0：M30当前最佳候选

该组合风险指标很漂亮：

- 最大回撤 2.43%
- 单 Basket 最大亏损 241.25
- Sharpe 1.574
- PF 1.261

但其平均持仓约 2.65 天，最长 Basket 达 **59.4 天**；回测结束仍有一个约 **195.9 小时（8.2 天）**的活动 Basket。因此，M30 的主要问题不是短期回撤，而是资本占用和尾部持仓时间。

## 6. 参数敏感性分析

### 6.1 ZScoreOpen：两个周期呈现相反方向

#### M15

| ZScoreOpen | 平均Score | Score中位数 | 最大Score | 平均Sharpe | 盈利组合比例 |
|---:|---:|---:|---:|---:|---:|
| 1.5 | -59.64 | -20.76 | 0.04 | -0.18 | 40% |
| 2.0 | 6.36 | 0.89 | 44.48 | 0.54 | 100% |
| 2.5 | 12.63 | 12.59 | 35.99 | 0.59 | 93% |
| **3.0** | **167.23** | **151.74** | **375.41** | **1.59** | **100%** |

M15 在 `ZScoreOpen = 3.0` 出现明显跃升，而且 3.0 正好是本轮搜索上限。因此当前不能简单得出“最佳值就是 3.0”，更合理的结论是：

> **M15 的最优首仓阈值可能仍在 3.0 以上，本轮尚未覆盖峰值。**

此外，低阈值并没有带来更高周转。`ZScoreOpen = 1.5` 的回测结束活动 Basket 持仓时间中位数约 1543 小时（约 64 天），而 `ZScoreOpen = 3.0` 约为 30 小时。说明过早入场可能导致 Basket 长时间被锁住，反而降低整体周转效率。

#### M30

| ZScoreOpen | 平均Score | 最大Score | 盈利组合比例 |
|---:|---:|---:|---:|
| **1.5** | **39.98** | **67.65** | **100%** |
| 2.0 | -11.82 | 5.33 | 73% |
| 2.5 | -26.37 | 0.99 | 53% |
| 3.0 | 0.22 | 0.52 | 100% |

M30 则恰恰相反，最佳表现集中在最低测试值 `1.5`。因此：

> **M30 下一轮应向 1.5 以下继续扩展，而不是继续提高首仓阈值。**

### 6.2 AddZStep：M15 的稳定平台更接近 2.0～2.5

M15 各加仓间距的平均 Score：

| AddZStep | 平均Score | 最大Score | 平均DD |
|---:|---:|---:|---:|
| 1.0 | 34.67 | **375.41** | **36.77%** |
| 1.5 | 8.10 | 153.21 | 20.03% |
| **2.0** | **42.89** | 283.37 | 13.34% |
| **2.5** | **42.71** | 192.89 | 10.23% |
| 3.0 | 29.86 | 151.74 | **6.36%** |

`AddZStep = 1.0` 可以制造最高收益尖峰，但总体回撤也显著更高；真正稳定的平均 Score 平台出现在 **2.0～2.5**。

这说明对 M15 来说，更宽的加仓间距能够减少在同一轮极端偏离中的过度堆仓。

## 7. 持仓尾部风险

虽然优质 M15 组合的平均 Basket 持仓普遍只有约 **1.7～1.9 天**，但最长持仓全部接近 **47 天**；M30 最佳候选平均持仓约 **2.65 天**，最长达到 **59.4 天**。

这说明持仓时间分布具有明显长尾特征：

> 大多数 Basket 可以较快回归，但少数结构性偏离会占用资金数周。

这仍然是当前“回归后必须盈利才平仓”机制的主要实盘风险之一。平均持仓时间不能替代最长持仓时间，后续评估必须持续同时观察二者。

本轮优秀 M15 组合的回测结束活动 Basket 年龄约 **30.2 小时**，相对健康；M30 最佳候选约 **195.9 小时（8.2 天）**，说明 M30 的尾仓问题更明显。

---

## 8. 极端 Z 持续时间

本轮所有重点 M15 组合的最大极端 Z 持续时间约 **1.21 小时**；M30 重点组合约 **2.94 小时**。

这说明在 OLS residual 模型下，本轮极端 Z episode 本身并没有长期持续几十小时，当前更主要的风险来自：

- 进场后价格/残差回归不足以令 Basket 整体盈利；
- 多层仓位的成本结构；
- “必须盈利平仓”导致的尾部 Basket 长期滞留。

因此，极端 Z 持续时间和 Basket 持仓时间必须分开理解。

## 9. 当前候选参数分层

### 9.1 收益型

**M15 / 3.0 / 1.0 / 0.04**

适合用于研究策略的收益上限，但当前回撤和单 Basket 风险偏大，不建议直接作为实盘默认参数。

### 9.2 激进平衡型

**M15 / 3.0 / 2.0 / 0.04**

在保持较高收益的同时，显著降低最大回撤和单 Basket 尾部风险，是比最高利润组合更合理的高风险收益候选。

### 9.3 平衡型首选

**M15 / 3.0 / 2.0 / 0.02**

当前最值得优先进行样本外验证。Sharpe 高、最大回撤低、单 Basket 最大亏损可控，且仍有一定绝对收益。

### 9.4 保守型

**M15 / 3.0 / 2.0 / 0**

不依赖加大后续层级手数也能保持较高 Sharpe 和很低回撤，是评估“加仓手数增量到底有没有真实增益”的重要基准。

### 9.5 M30候选

**M30 / 1.5 / 1.5 / 0**

回撤和单 Basket 损失非常低，但持仓尾部更长。适合继续研究低频、等手数版本，但不应与 M15 共用一套参数逻辑。

## 10. 下一轮优化建议

本轮最大的两个信息是：

1. **M15 最优 `ZScoreOpen=3.0` 撞到搜索上边界**；
2. **M30 最优 `ZScoreOpen=1.5` 撞到搜索下边界**。

因此下一轮不应继续在原区间内机械细化，而应分别向边界外扩展。

### M15：建议 36 组

| 参数 | 建议取值 |
|---|---|
| ZScoreOpen | 3.00、3.25、3.50、3.75 |
| AddZStep | 1.5、2.0、2.5 |
| AddLotStep | 0.01、0.02、0.03 |

共 `4 × 3 × 3 = 36` 组。

目标：确认 M15 的 OpenZ 峰值是否在 3.0 以上，并进一步验证 `AddZStep≈2.0`、`AddLotStep≈0.02` 是否属于稳定平台。

### M30：建议 36 组

| 参数 | 建议取值 |
|---|---|
| ZScoreOpen | 1.00、1.25、1.50、1.75 |
| AddZStep | 1.0、1.5、2.0 |
| AddLotStep | 0、0.01、0.02 |

共 `4 × 3 × 3 = 36` 组。

目标：判断 M30 真正的 OpenZ 峰值是否低于 1.5，并确认等手数是否持续占优。

两部分共 **72 组**，比扩大网格更有效率。

## 11. 最终判断

本轮已经成功完成了“参数方向定位”，但还没有完成“最终参数确认”。

当前最有价值的结论是：

1. **M15 与 M30 应视为两套不同风格的策略，而不是同一个参数模型。**
2. M15 应提高首仓质量，`ZScoreOpen≈3+` 明显优于低门槛。
3. M15 的加仓间距更适合 **2.0～2.5Z**，避免 1.0Z 密集加仓造成尾部风险放大。
4. M15 线性增仓 `0.02` 当前最均衡；`0.04` 更像收益放大型而非稳定最优。
5. M30 明显偏好较低入场阈值和等手数加仓。
6. 当前重点候选中，**M15 / 3.0 / 2.0 / 0.02** 是最适合作为下一轮样本外验证基准的组合。
7. 即使优秀组合平均持仓只有约 2 天，最长 Basket 仍达到 47～59 天，因此**尾部持仓风险仍是整个策略后续最需要解决的问题**。
8. 下一步必须进行边界外扩展、不同时间区间的样本外测试和参数平台验证，不能直接依据本轮 Score 第一名确定实盘参数。
